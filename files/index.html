    Only the owner. Withdrawal authority never leaves the owner. It stays enabled in Active, Paused, Revoked, and Expired.

    Is this a vault?+

    MVP is separately managed accounts: one mandate per depositor. Funds do not commingle. Pooling is a later decision, default still SMA.

    Is the agent an LLM?+

    No. The book-core is deterministic and must run if every model is down. The risk guard is thresholds. A model may propose. An LLM never signs.
